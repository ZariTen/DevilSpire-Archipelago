# Devil Spire x Archipelago

An [Archipelago](https://archipelago.gg) multiworld add-on for **Devil Spire**.
Fan-made. Not affiliated with the game's developer or the Archipelago project.
You need your own copy of Devil Spire on **Steam**. No game files are included.

> Early version (0.1.0). Expect bugs.

## How it plays
- You play one mode: **Archipelago** (100 floors down).
- Reaching floors, beating bosses, opening chests and buying Archipelago Items in shops sends items to other players.
- Items you receive come to you at the camp. Equipment lies on the ground around you.
- If you die, you start a new run and get all your items again.
- Beat the boss on floor -100 to win.

## Quick install (players)
1. Install [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases) 0.6.8 or newer.
2. Download `devilspire.apworld` from [Releases](../../releases) and double-click it.
3. In the Archipelago Launcher, open **Devil Spire Client** and type `/auto_patch`.
4. Connect the client to the server.
5. Start Devil Spire from Steam and choose *New Game*.

Full steps and help: [Player guide](docs/PLAYER_GUIDE.md).
Hosting a game: [Host guide](docs/HOST_GUIDE.md). Only the host and Devil Spire players need the apworld.
