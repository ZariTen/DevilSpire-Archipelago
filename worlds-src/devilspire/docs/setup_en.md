# Devil Spire Setup Guide (fan-made, WORK IN PROGRESS)

The in-game patch and client do not exist yet; this page only covers the generation side.

## Requirements
- A legitimate copy of Devil Spire (the patch will be applied to a *copy*; no game files are ever distributed).
- Archipelago 0.6.9 or newer.
- `devilspire.apworld` in Archipelago's `custom_worlds` folder (or `worlds/` when running from source).

## Generating a game
1. Create a YAML (Options page / template via the Launcher "Generate Template Options").
2. Put it in `Players/`, run Generate, host the result.
